# 🪐 幻兽戴森 PalDyson

**帕鲁（幻兽帕鲁）× 戴森球计划** 风格的俯视角 2D 基地建设游戏 —— 全程程序化生成的复古像素风，零外部美术资源，纯浏览器运行。

> 一句话生成：一个把"驯化帕鲁打工"和"传送带自动化工厂"结合起来的 2D 基地建设游戏。

## ✨ 玩法特色

| 系统 | 说明 |
|---|---|
| 🏗️ **基地建设** | 网格化建造：风力/燃煤发电、采矿机、熔炉、组装机、研究所、储物箱、传送带… |
| 🔗 **戴森球式物流** | 传送带自动运输物品：建筑正面输出 → 传送带 → 相邻建筑输入，全自动化流水线 |
| 🟣 **帕鲁驯化** | 投掷帕鲁球捕获 5 种野生帕鲁（芽芽兽/岩岩兽/火苗鸟/雷雷鼠/泡泡鱼），指派到建筑打工（特长 ×2 效率），需要喂浆果维持饱食与心情，还能带一只跟随加速采集 |
| ⚡ **电力系统** | 风力随机波动 vs 燃煤稳定供电；电力不足时全线生产减速 |
| 🔬 **科技树** | 研究所消耗矿石+煤炭合成红色科技瓶，自动推进 6 项科技：冶金 → 自动化 → 物流 → 帕鲁驯化 → 燃煤发电 → 戴森工程 |
| 🪐 **终极目标** | 向戴森环核心投入 10 个戴森组件，点亮戴森环，获得胜利结算 |
| 🌙 **昼夜循环** | 白天/黑夜光照变化，帕鲁夜间入睡，风力随时间波动 |
| 💾 **存档** | 自动保存 + 手动保存（localStorage），支持继续游戏，含存档版本迁移 |

## 🎮 操作

| 键位 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 鼠标左键 | 采集 / 交互 / 放置建筑 / 投掷帕鲁球 |
| E | 采集最近资源；建造时旋转方向 |
| Q | 旋转放置方向 |
| 1-9, 0 | 快捷栏选择建筑 |
| B | 建造菜单 |
| S（热键栏旁） | 帕鲁球投掷模式 |
| F | 喂跟随帕鲁 |
| 右键 / Esc | 取消 / 关闭 |

## 🛠 技术栈（调研结论）

- **Phaser 3** —— 2D 游戏框架：tilemap、Arcade 物理、相机、输入、Tween 一应俱全。对比 Three.js（3D 向）与裸 PixiJS（无游戏循环/碰撞），Phaser 是俯视角 2D 的最优解。
- **Vite + TypeScript** —— 极速 HMR 开发体验 + 全量严格类型检查（`strict`）。
- **程序化像素美术** —— 所有贴图为手写 pixel map（字符串数组 + 调色板）经运行时生成；`pixelArt: true` 关闭抗锯齿；配 CRT 扫描线滤镜。
- **缝合像素字体 Fusion Pixel**（OFL-1.1，已随仓库分发于 `public/fonts/`）—— 中文像素字体，离线可用。
- **WebAudio 程序化音效** —— 无音频资源。
- **DOM 覆盖层 UI** —— 游戏世界用 Phaser 渲染，HUD/菜单用 DOM（像素风 CSS），互不干扰。

