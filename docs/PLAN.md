# 项目计划 PLAN.md — 幻兽戴森 PalDyson

## 1. 一句话需求

做一个"幻兽帕鲁 + 戴森球计划"合体的、主打基地建设的俯视角 2D 游戏；
技术选型自由、开源库不限、创意优先、在可完成范围内做到最好；
独立文件夹、GitHub 备份、项目管理和代码审查。

## 2. 技术栈调研（结论与理由）

| 候选 | 结论 | 理由 |
|---|---|---|
| Three.js | ❌ 不用 | 面向 3D；本项目是 2D 俯视角网格游戏，引入 3D 渲染徒增复杂度 |
| 裸 PixiJS | ❌ 不用 | 只是渲染器，游戏循环/物理/碰撞/tilemap 都要自己写 |
| **Phaser 3** | ✅ 选用 | 2D 游戏框架事实标准：Tilemap（海量瓦片高效渲染+碰撞）、Arcade 物理、相机跟随、指针/键盘输入、Tween（投掷/动画）、Graphics 运行时生成纹理 |
| Canvas 2D 手写 | ❌ 不用 | 重复造轮子 |
| **Vite + TypeScript(strict)** | ✅ 选用 | 秒级 HMR；strict 模式对 4k+ 行代码库是刚需；零配置打包 |
| DOM 覆盖层 UI | ✅ 选用 | 复杂面板（科技树/帕鲁管理/建筑面板）用 DOM+CSS 实现远比 Phaser Text 高效美观，点击穿透用 pointer-events 控制 |
| 美术 | 程序化像素风 | 无生图/多模态能力 → 用"手写 pixel map + 调色板 + pixelArt 渲染 + CRT 滤镜"做刻意的像素美学，风格统一且零版权风险 |
| 字体 | Fusion Pixel (OFL) | 中文像素字体，下载后随仓库分发，离线可用 |
| 音效 | WebAudio 合成 | 程序化生成，无音频资产 |
| 存档 | localStorage | 单机浏览器游戏，无后端需求 |

## 3. 游戏设计（帕鲁 × 戴森球）

- **循环**：手工采集（树/石/铁矿/煤矿/浆果）→ 建风力发电 + 采矿机 → 熔炉炼铁 → 组装机做齿轮/电路板 → 研究所产红瓶研究科技 → 解锁传送带/帕鲁球/燃煤/戴森 → 自动化流水线 + 帕鲁打工 → 10 个戴森组件点亮戴森环（胜利）。
- **帕鲁**：5 种（芽芽兽/岩岩兽/火苗鸟/雷雷鼠/泡泡鱼），稀有度不同；帕鲁球投掷捕获（带抛物线 + 命中判定 + 失败逃跑）；指派到建筑打工（特长 ×2、其他 ×1.2），饱食/心情管理，跟随帕鲁加速采集。
- **物流**：传送带为"1 瓦片带方向"的段；物品在段内 0..1 前进，链式传递；从建筑正面输出口拉货，推入相邻建筑输入口（按可接受物品过滤）；储物箱全向缓冲。
- **电力**：全局电网无线供电（简化戴森球的无线输电）；风力波动 vs 燃煤稳定；赤字时按比例降速（可玩性强于直接断电）。
- **科技树**：红瓶由研究所生产（矿石+煤炭），研究自动消耗研究所缓存的红瓶 —— 逼你建传送带物流。
- **失败条件**：无（沙盒向），胜利后可继续玩。

## 5. 风险与取舍

- 传送带物品不随存档持久化（保存时停留在带上的物品会丢失）—— 可接受，文档化。
- 无战斗系统（帕鲁不参战）—— 聚焦"建设 + 自动化"主题。
- 帕鲁 AI 为简单游荡 + 逃跑，无寻路 —— 2D 俯视角足够。
- WebGL 纹理上限：地形用 Tilemap 单张 tileset（5 瓦片条带），无超大纹理。
