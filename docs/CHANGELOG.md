# 变更日志 CHANGELOG.md

## [0.1.0] — 首个可玩版本

### 新增
- 完整游戏循环：采集 → 发电 → 采矿 → 冶炼 → 组装 → 科研 → 物流 → 帕鲁 → 戴森环胜利
- 种子化 96×96 地图生成（湖泊、铁矿/煤矿脉、浆果丛、树、岩石）
- 10 种可建造建筑 + 6 种配方 + 6 项科技
- 5 种野生帕鲁（像素点阵绘制）捕获与打工系统
- 传送带自动化物流（段式物品运输、建筑拉货/收货、方向过滤）
- 全局电力网格（风力波动 / 燃煤 / 赤字降速）
- 昼夜循环、程序化 WebAudio 音效、localStorage 自动存档
- 刻意像素风：pixel map 程序化贴图、pixelArt 渲染、CRT 扫描线滤镜、缝合像素中文字体（OFL）

### 技术
- Vite + TypeScript strict + Phaser 3.90
- 全系统无外部美术/音频资产

### 已知限制
- 传送带上的物品不随存档持久化（保存时丢弃，可接受）
- 无战斗系统；帕鲁无寻路（游荡 + 逃跑）
